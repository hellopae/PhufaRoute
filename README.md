# PhufaRoute — แผนส่งสิ่งพิมพ์ภูฟ้า 2570

เวปวางแผนเดินสายส่งสิ่งพิมพ์ให้ร้านภูฟ้าทั่วกรุงเทพฯ ของ TANAPAT Printing

**ดูเวป:** https://hellopae.github.io/PhufaRoute/

## มีอะไรบ้าง

- **แผนส่ง 5 วัน** จัดกลุ่มสาขาตามโซน (ยุบเหลือ 4 วันได้) พร้อมเวลาแนะนำรายจุด
- **แผนที่เส้นทางรายวัน** ในการ์ดแต่ละวัน — หมุดเลขลำดับ + ป้ายชื่อ เส้นตามถนนจริง และ "ลำดับการวิ่ง" บอกระยะทาง/เวลาขับระหว่างจุด (กดชื่อหรือหมุดเพื่อเลื่อนไปการ์ดสาขา)
- **แผนที่** Leaflet + OpenStreetMap หมุดแยกสีตามวัน มีเส้นลำดับการวิ่ง
- **ปุ่มเส้นทาง Google Maps** ทั้งวันในลิงก์เดียว (waypoints) และลิงก์หมุดร้านภูฟ้ารายสาขา
- **ตารางทุกสาขา** ชั้น เวลาเปิด-ปิด เบอร์โทร ลิงก์แผนที่ และจำนวนของแยกตามชนิดงานพิมพ์ (การ์ดรายสาขาแยกตามสีด้วย)
- **เช็คลิสต์** คำถามที่ต้องโทรถามก่อนไป + ของที่ต้องมีติดรถ
- ติ๊กสาขาที่ส่งแล้ว (เก็บใน localStorage ของเครื่องนั้น) และสั่งพิมพ์หน้าได้

## โครงสร้าง

ไฟล์เดียว ไม่มี build step — `index.html` มีทั้ง CSS, ข้อมูลสาขา และสคริปต์อยู่ในตัว
deploy ผ่าน GitHub Pages จาก `main` / root (มี `.nojekyll` กันไม่ให้ Jekyll ประมวลผล)

### แก้ข้อมูลสาขา

ข้อมูลทั้งหมดอยู่ในตัวแปร `B` (สาขาที่ต้องส่ง), `DAYS` (คำอธิบายแต่ละวัน) และ
`CLOSED` (สาขาปิดปรับปรุง) ในบล็อก `<script>` ท้ายไฟล์

ฟิลด์สำคัญของแต่ละสาขา:

| ฟิลด์ | ความหมาย |
|---|---|
| `day` / `seq` / `eta` | วันที่ส่ง · ลำดับจุดในวันนั้น · เวลาแนะนำ |
| `lat` / `lng` | พิกัดหมุด |
| `gmap` | ลิงก์ Google Maps ของร้าน (ไม่มี = ปักหมุดตาม `lat`/`lng`) |
| `c` | จำนวนแยกสี `[สคส.[ม่วง,เหลือง,ฟ้า,แดง], สมุดเล็ก[ม่วง,ฟ้า], สมุดใหญ่[ม่วง,ครีม]]` |
| `reg` | ประเภทการลงทะเบียน — `none` `mall` `office` `hospital` `market` `gov` |
| `offmap:true` | ไม่ขับไปเอง (หัวหิน/น่าน ฝากส่งต่อที่สำนักงาน) — ไม่ขึ้นหมุดและไม่อยู่ในเส้นทาง |

ถ้าจำนวนของเปลี่ยน แก้ที่ `c` อย่างเดียว — ยอดรวมทุกจุดในหน้า (รวมแถวรวมท้ายตาราง) คำนวณเอง
ข้อความในคำอธิบายวัน (`DAYS[].note`) แท็ก และแท็บเช็คลิสต์ที่อ้างตัวเลขชิ้น ยังเป็นข้อความพิมพ์ไว้ ต้องแก้ตาม
เส้นทางถนนดึงจาก OSRM (`router.project-osrm.org`, ข้อมูล OpenStreetMap) แล้วจำไว้ใน localStorage คีย์ `phufa-route-<พิกัด>` — แก้พิกัดหรือย้ายลำดับแล้วคีย์เปลี่ยนเอง ถ้าโหลดไม่ได้จะกลับไปใช้เส้นประตรงๆ แทน · เวลาขับไม่รวมรถติด
ลำดับในแผนที่ใช้เลขจุดจอดจริง (สาขาที่พิกัดซ้ำกันรวมเป็นจุดเดียว) ไม่ใช่ `seq`
ติ๊ก "ส่งแล้ว" เก็บใน localStorage คีย์ `phufa-done-2570` — ขึ้นปีใหม่ให้เปลี่ยนคีย์ ไม่งั้นติ๊กของปีเก่าจะค้าง

## ที่มาของข้อมูล

- จำนวนงานพิมพ์ — `ร่างตารางสิ่งพิมพ์ 2570.xls` (สคส. 10,000 / สมุดเล็ก 3,000 / สมุดใหญ่ 2,000 แยกสี) ใน `Work Tanapat/Phufa/ปีมะแมแพะ 2570/Files/`
- ชั้น เวลารับของ ที่จอดรถ การจัดกลุ่มซ้าย-กลาง-ขวา — Google Doc ของเจ้าของ
- ที่อยู่ เบอร์โทร เวลาเปิด-ปิด — [phufa.org/branch-all](https://www.phufa.org/branch-all/) และ [phufa.org/contact](https://www.phufa.org/contact/)
- พิกัดหมุด + ลิงก์ — Google Maps ที่ภูฟ้าลิงก์ไว้หน้า branch-all (ลิงก์ของบิ๊กซี พระราม 4 ในเวปภูฟ้าชี้ผิดไปราชดำริ จึงใช้พิกัด OpenStreetMap)

> ⚠️ ข้อมูล "ต้องลงทะเบียนไหม" เป็นแนวปฏิบัติทั่วไปของห้าง/โรงพยาบาล **ยังไม่ได้ยืนยันรายสาขา**
> ต้องโทรนัดก่อนไปทุกครั้ง (มีชุดคำถามอยู่ในแท็บ "วิธีส่ง / เช็คลิสต์")
